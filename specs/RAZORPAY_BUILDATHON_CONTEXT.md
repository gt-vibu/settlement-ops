# Razorpay Buildathon Context (Public-Source Grounding)

## Current public brief used for this specification

Razorpay's public Buildathon page describes the program as a student-only effort to build real AI, show a public repo, a five-minute pitch, and the architecture. Track 4 is the AI Finance Controller track and asks for an agent that closes one finance-ops loop across a 50+ record synthetic batch, with throughput, measured accuracy and honest exceptions. Source: https://razorpay.com/buildathon/ (reviewed 2026-08-31).

## Relevant public product context

Razorpay publicly describes:

- an Agentic Platform for onboarding, integration, analytics and operations;
- Agent Studio for specialized operational AI agents;
- Intelligent Reconciliation capabilities in its agentic dashboard narrative;
- Agentic Connected Banking / RazorpayX agents for finance operations;
- public settlement and settlement-reconciliation APIs.

## Interpretation rule

These sources establish product/domain context and explicit public capabilities. They do not establish what Razorpay's private internal architecture or hiring panel implementation criteria are beyond what the public Buildathon page states.

The project therefore avoids claims such as “Razorpay does not have X” and instead focuses on a concrete finance-operations workflow that can be built and evaluated independently.
