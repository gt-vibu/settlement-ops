## Implementation rule

The coding agent must inspect the repository before changing code. UI/frontend work is explicitly excluded from the current implementation scope.

## Product in one sentence

A persistent finance-operations control center that reconciles the normal payment-to-settlement flow and uses bounded AI to investigate the difficult residual, with deterministic verification and human approval.
