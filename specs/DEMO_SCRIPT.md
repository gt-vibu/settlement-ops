# Demo Script — Five Minutes

## 0:00–0:30 — Open the product

Show the finance operations control center. Point to current open exceptions and the persistent queue.

## 0:30–1:00 — Create a scenario

Instantiate a controlled ₹10,000 payment scenario with a selected settlement defect.

## 1:00–1:30 — Watch the lifecycle

Show Order -> Payment -> Capture -> Fee/Tax -> Settlement -> Bank -> Ledger. Let the backend create the actual records and exception.

## 1:30–2:30 — Investigate

Open the exception. Show what deterministic reconciliation already knows. Start investigation. Show hypotheses and evidence retrieval.

## 2:30–3:15 — Verify

Show the model proposal and then the deterministic verifier result. Use a strong case where the verifier validates the proposal.

## 3:15–4:00 — Approval and state change

Approve the staged action. Show the persistent state change and audit event.

## 4:00–4:30 — Show a failure/abstention case

Open an ambiguous case. The agent cannot prove a unique cause and escalates.

## 4:30–5:00 — Show evidence

Show benchmark comparison, unsupported-resolution rate, challenge-set behavior and verifier-overrides. State limitations honestly.
